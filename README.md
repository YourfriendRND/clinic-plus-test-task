# Тестовое задание для компании "Клиника Плюс"

## Разрботать систему создания и выполнения абстрактных(без конкретной сферы исполнения) заказов на выезд бригад.

### Тех.стек: Node express, React (можно NextJS), TS, RabbiMQ, Redis, TypeORM, PostgreSQL.

Модули Веб-приложения (оно же админка для операторов и личный кабинет для бригад для упрощения):

1. Авторизация (имитация 2-х факторной по телефону или email).
2. Для операторов:
    - Список нарядов.
    - Модалка создания\редактирования наряда, Проставление наряда на бригаду.
    - Список бригад.
    - Websoket подключение для отслеживания исполнения наряда.
3. Для бригад:
    - Список проставленных на исполнение нарядов по конкретной бригаде.
    - Модалка для выполнения наряда.
    - Websoket подключение для отслеживания новых нарядов.

Модули серверных приложений:

1. Авторизации с хранением сессий.
2. CRUD запросов по сущностям системы.
3. Балансировщик запросов.
4. Websoket подключений с уведомлениями для операторов и бригад.

Основные сущности.

Роль:

- id
- название
- code (operator\team)

Пользователь:

- uuid
- ФИО
- телефон
- пароль
- роль

Наряд:

- uuid
- исполнитель
- дата выполнения
- адрес
- статус (новый\в работе\выполнен)
- описание
